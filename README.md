# pension-calculator
Калькулятор пенсии за выслугу лет – бесплатный онлайн-инструмент для предварительного расчёта пенсий госслужащих (ФЗ №166) и военных/правоохранителей (Закон №4468-1). Учитывает стаж в годах/месяцах, понижающий коэффициент, смешанный стаж и фиксированную выплату 9 584,69 ₽. Результат – с копейками.
